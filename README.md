# 🌸 Pink Stopwatch

A beautiful, interactive, and fully functional stopwatch web application built with HTML5, CSS3, and modern JavaScript. 

## ✨ Features
* **Full Time Tracking:** Measures Hours, Minutes, and Seconds with neat formatting (`00:00:00`).
* **Interactive Controls:** Dynamic buttons that switch between **Start**, **Stop**, **Resume**, **Reset**, and **Lap**.
* **Smooth Animations:** Includes a smooth pulse animation effect when the timer is running.
* **Aesthetic UI:** Designed with a cozy, modern pink theme inspired by mobile stopwatch apps.

## 🛠️ Built With
* **HTML5** - Structure and layout.
* **CSS3** - Styling, flexbox, and keyframes animations.
* **JavaScript (ES6)** - Stopwatch logic, DOM manipulation, and event handling.

## 🚀 . Open `index.html` in your favorite web browser and enjoy!
